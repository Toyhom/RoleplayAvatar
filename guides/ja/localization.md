# 多言語

[English](../localization.md) · [简体中文](../zh-CN/localization.md) · [日本語](localization.md)

画面と全ガイドは英語、簡体字中国語、日本語で利用できます。上部の言語セレクターで切り替えます。初回はブラウザーの言語を選び、その後は選択を保存します。`/?lang=ja` で日本語を直接開けます。切り替えでは画面を再読み込みし、キャラクター、会話、未送信メッセージを保持します。

ナビゲーション、作成、声の選択、録音状態、会話、演技操作、動作メッセージを共通の言語表で扱います。キャラクター名、設定、インポート素材の出典、会話内容は元の文章を保持します。

## 作成と音声

画像作成と Live2D の読み込みは `locale` を送り、設定、参照台詞、VoiceDesign の言語に使います。API は `en`、`zh-CN`、`ja` に対応し、互換性のための既定値は `zh-CN` です。`/api/agents/character-design` も同じフィールドを使います。会話ではユーザーの明示した言語、またはメッセージの言語に従います。

多言語マイクには Whisper `--language auto` を使うか、言語を固定できます。既存の声は元の録音を保持します。別言語の参照音声を作る場合は、その言語でキャラクターを作成してください。

## 言語を追加する

1. `web/locales/` に `en.js` と同じキー・位置プレースホルダーの言語表を追加します。UI の文言はモデル生成内容と独立しています。
2. `web/i18n.js` に登録し、`web/index.html` に選択肢を加え、`normalizeLocale` を更新します。
3. 作成言語を増やす場合は、音声モデルが対応する言語を `languages.py` の `Locale`、`LANGUAGES`、`VOICE_VARIATIONS`、`VOICE_RECORDING` に追加します。
4. 全ガイドと README のナビゲーションを翻訳します。`scripts/check_docs.py` が三言語のページ一覧とリンクを確認します。
5. `node --test tests/*.test.mjs` と `python scripts/check_localization.py --url http://localhost:18080` を実行します。デスクトップ・モバイル、ダイアログ、言語切り替え、空の会話再利用、書き出しを確認します。

静的翻訳は入れ子の要素を維持し、動的文言は `t()` を明示的に呼び出します。プレースホルダーはテキストとして挿入します。UI の文言は言語表、キャラクター内容とバックエンドの詳細はデータとして扱います。
