# Codex / Claude Code でセットアップする

[English](../ai-setup.md) · [简体中文](../zh-CN/ai-setup.md) · [日本語](ai-setup.md)

AI コーディングツールでリポジトリを開き、次の文章をコピーします。保存先やモデルに希望がある場合は記入してください。

```text
このリポジトリに Roleplay Avatar をセットアップし、実際の動作を確認してください。
目的：2D キャラクターとの会話、Live2D インポート、マイク入力。
モデル保存先：[指定、または推奨]
新しい環境の保存先：[指定、または専用ディレクトリを推奨]
モデル：[ハードウェアに合わせて推奨 / compact / balanced / quality / showcase / API]
ダウンロード元：[Hugging Face / https://hf-mirror.com / その他]
希望する言語：日本語。

README.md、guides/setup.md、guides/models.md と適用されるワークスペースの
指示を読み、Python、Node、利用可能な GPU、空き容量、既存モデルを確認してください。
完全な互換モデルがある場合は再利用し、管理された GPU キューがある環境では
そのアカウントとキューの手順を使用してください。

1. 会話用・作成用モデル、必要メモリ、同時に動かすサービスを説明する。
   API の場合はモデル ID、地域別 URL、キーの環境変数を確認する。
2. 指定先に専用環境を作り、Web アプリをインストール、フロントエンドを
   ビルドし、CPU テストを実行する。モデル依存はサービス別環境に入れる。
3. avatar models recommend/list/download/configure を使い、計画を確認して
   指定元から固定リビジョンを取得・検証する。必要な上流コードと顔・前景の
   補助リソースもインストールする。
4. .local.env と configs/models.local.json に実際のパス、Python、各エージェントの
   モデルと URL を設定する。キー本体は環境変数で管理する。
   自由形式の役モデルは actor_director とし、制御タスクには汎用指示モデルを使う。
   プロンプトと音声設計文を日本語向けに設定し、ASR は auto または ja とする。
5. GPU ランナーで推論サービスを起動してから Web を起動し、/healthz と
   /api/services を確認する。Live2D サンプルを選んだ場合はリソースと
   参照音声を準備してインポートする。
6. 実際の返答、音声、表情・動作、中断、新しい会話、JSON 書き出しを検証する。
   マイクと、選んだ構成のキャラクター作成・インポートも確認する。
7. URL、使用モデル、検証結果、起動・停止コマンドを報告する。
   失敗した場合は調査を続けるか、失敗した手順と具体的な依存条件を示す。

API のみの利用は guides/api.md、独自モデルや研究手法の接続は
 guides/research.md を参考にし、モデル・プロンプト・生成設定を分離してください。
```

[モデルと設定](models.md)からプリセットやプロバイダーの詳細へ進めます。
